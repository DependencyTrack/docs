# Upgrading to v5.2.2

* **The API server container image mitigates CVE-2026-114938**. The vulnerability
  affects OpenJDK 17 and later on x64 processors with the AVX-512 VBMI instruction set. Adoptium had not published
  Temurin builds with the fix when v5.2.2 shipped, so the image applies the
  [workaround that Adoptium recommends](https://adoptium.net/news/2026/11/temurin-november-2026-cspu-java4shell):
  it adds `-XX:-UseBASE64Intrinsics` to the default [JVM options](../../reference/configuration/application.md#jvm-options).

    If you replace `JAVA_OPTIONS`, your value drops the flag. Add `-XX:-UseBASE64Intrinsics` to it,
    or move your flags to `EXTRA_JAVA_OPTIONS`, which extends the defaults instead of replacing them.

    If you run the API server outside the official container image, add the flag to your Java command line,
    or upgrade to a Temurin build that includes the fix.

* **ENISA EU KEV mirroring fails until you update the feed URL**. ENISA moved its KEV catalog, and the old URL
  returns HTTP 404. New installations use the new URL, but existing installations keep the URL stored in their
  configuration. To update it:

    1. Open **Administration > KEV Sources > ENISA EU KEV**.
    2. Set **Feed URL** to `https://raw.githubusercontent.com/enisaeu/CNW/main/eukev/eukev.json`.
    3. Select **Save**.
    4. Select **Mirror now** to download the catalog immediately.

    See [Configuring KEV sources](../administration/configuring-kev-sources.md#enisa-eu-kev) for details.

* **Component policies with vulnerability conditions honor rating overrides**. Earlier versions evaluated
  conditions against the original severity and the original CVSS and OWASP ratings of a vulnerability,
  and ignored overrides from finding analyses. Policy violations can appear or disappear the next time
  Dependency-Track evaluates policies for a project.
